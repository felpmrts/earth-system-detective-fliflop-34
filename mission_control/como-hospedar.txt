3. Quick Local Network (LAN / Team Wi-Fi) Hosting Guide

So the entire team can access the dashboard from a single host machine connected to the same Wi-Fi during the hackathon:

Step 1: Find the Local IP of the Host Machine

In the Linux terminal of the machine hosting the dashboard, run:

bash
hostname -I | awk '{print $1}'

(Example output: 192.168.1.42)

Step 2: Start the HTTP Server in the Project Folder

Choose either option below by running the command inside the "Space Apps" folder:

Option A — Via Python 3 (http.server) (Recommended — Zero installation)
bash
python3 -m http.server 8080 --bind 0.0.0.0 --directory "/home/zrhyan/Principal/Computation/Space Apps/mission_control"
Option B — Via Node.js (npx serve)
bash
npx serve -l tcp://0.0.0.0:8080 "/home/zrhyan/Principal/Computation/Space Apps/mission_control"
