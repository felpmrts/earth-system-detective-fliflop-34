3. Guia Rápido de Hospedagem em Rede Local (LAN / Wi-Fi da Equipe)

Para que toda a equipe acesse o painel a partir de uma única máquina host conectada ao mesmo Wi-Fi durante o hackathon:

Passo 1: Descobrir o IP Local da Máquina Host

No terminal Linux da máquina que vai hospedar o painel, execute:

bash
hostname -I | awk '{print $1}'

(Exemplo de saída: 192.168.1.42)

Passo 2: Iniciar o Servidor HTTP na Pasta do Projeto

Escolha qualquer uma das três opções abaixo executando o comando dentro da pasta "Space Apps":

Opção A — Via Python 3 (http.server) (Recomendado — Zero instalação)
bash
python3 -m http.server 8080 --bind 0.0.0.0 --directory "/home/zrhyan/Principal/Computation/Space Apps/mission_control"
Opção B — Via Node.js (npx serve)
bash
npx serve -l tcp://0.0.0.0:8080 "/home/zrhyan/Principal/Computation/Space Apps/mission_control"
